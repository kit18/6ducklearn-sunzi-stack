# Tool-Book Family Tree AI-Agent Plan

Input basis: user-provided reading notes from the thread, limited to book titles,
user highlights, and intended application. This is an original synthesis for AI
agent design, not a copied book summary or authoritative full-book digest.

## Reader Digest

1. Sunzi-for-business books should make the agent start from terrain, actors,
   timing, restraint, and asymmetric leverage before naming tactics.
2. Executive Sunzi framing should make the agent check command clarity: who owns
   the decision, who can block it, and what must be true before action.
3. Business-war case learning should make the agent look for rivalry patterns,
   second-order responses, and the cost of winning the wrong battle.
4. McKinsey-style problem-solving books should make the agent decompose the
   question with MECE / logic-tree discipline before using SWOT or slogans.
5. 3C and Porter-style tools should make the agent separate customer reality,
   internal capability, competitor reaction, and industry profit pressure.
6. SWOT should be treated as synthesis after evidence, not as the starting
   method.
7. PDCA should make the agent turn strategy into an operating loop with owner,
   cadence, metric, learning rule, and stop / adjust criterion.
8. Presentation tools should make the agent finish with a one-slide storyline:
   decision, tension, evidence, strategic move, risk, and stop rule.

## Evidence Needed

- User-provided reading notes or authorized excerpts.
- Evidence ledger for the live AI-agent workflow.
- Adoption telemetry: weekly active workflow, task completion, override rate,
  time to value.
- Customer economics: margin, CAC / payback impact, refund or support cost,
  inventory or capacity opportunity cost.
- Risk evidence: complaint rate, escalation count, compliance issue, trust
  signal, error recurrence.

## Misuse Risk

- Treating book titles as proof.
- Turning the digest into a chapter-by-chapter summary.
- Adding consulting jargon without changing an agent behavior.
- Using synthetic expert-panel comments as real consulting-firm endorsement.

   advantage, and transformation/deck archetypes.
