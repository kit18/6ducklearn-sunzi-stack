## Original Reader Digest

1. Strategic books help the agent see terrain before tactics: market structure,
   actors, timing, trust, and constraint.
2. Executive strategy books push the agent to name decision rights, owner,
   escalation path, and what must be true before action.
3. Business-war case learning reminds the agent that rivalry creates
   second-order responses; the best move may avoid the visible fight.
4. Consulting method books make the agent decompose the problem before selecting
   a framework or Sunzi lens.
5. Operating-loop methods turn advice into cadence: plan, act, check evidence,
   adjust, or retreat.
6. Presentation methods force an answer-first narrative: decision, tension,
   evidence, move, risk, and stop rule.
